## ⚡ Overview

A high-performance personal portfolio tailored with a retro CRT cyberpunk terminal aesthetic, interactive bash shell (`whoami`, `projects`, `clear`, `contact`), live background data streams, animated retro pixel shaders, and verifiable track records.

### Highlights
- 🖥️ **Interactive Terminal & Command Line**: Executable terminal commands with tab-autocompletion and responsive shell output.
- 🎨 **Retro Cyberpunk CRT Visuals**: Bayer-dithered pixel portrait shader, scanlines, matrix number animations, and glowing neon controls.
- 💼 **Project Command Center**: Flagship showcase of **KiroKash** (1st Place Hackathon Winner at KrackedDev Build Day) and verified open-source initiatives.
- 🏆 **Track Record & Recognition**: Verifiable timeline spanning hackathon wins, finalist brackets (Google GDG @ UTM, PuO), student project leadership, and Dean's List distinctions.
- ⚡ **Deploy-Ready**: Optimized for instant deployment on Vercel or GitHub Pages.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm / pnpm / yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/airilakio29/portfolio.git

# Navigate into the project directory
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be accessible at `http://localhost:5173`.

### Production Build

```bash
npm run build
npm run preview
```
